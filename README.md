# Bash Automation Toolkit

## Project Overview
A beginner-friendly Bash automation project built to practice Linux shell scripting and automate basic system administration tasks.

## Features
- Check whether a file exists
- Check whether a directory exists
- Print numbers using loops
- Use if/else conditions
- Use for and while loops
- Handle errors and exit status
- Interactive menu using case statements

## Technologies
- Ubuntu Linux
- Bash Scripting
- Git
- GitHub
